<!-- TEST-ARCH.md risk score schema (WKFL-06, Claude's Discretion for rubric specifics). -->

Risk tiers:
- P0: safety-critical — auth, permissions, money flow, data loss; always in CI pre-merge
- P1: core behavior — primary happy paths, state machines, invariants; in CI pre-merge
- P2: secondary behavior — non-critical edge cases, performance; in CI post-merge or nightly
- P3: opportunistic — exploratory, low-value paths; local only, not gated

CI tiers:
- ci_tier: "pre-merge" — blocks PR merge
- ci_tier: "post-merge" — runs after merge, non-blocking
- ci_tier: "nightly" — scheduled, non-blocking
- ci_tier: "local-only" — never in CI pipeline
