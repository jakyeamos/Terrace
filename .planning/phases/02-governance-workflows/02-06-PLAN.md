<!-- Cumulative tier semantics required by FRAG-02 (loading higher tiers includes lower). -->

Tier loading semantics:
- tier='core'        → load only core fragments
- tier='extended'    → load core + extended fragments (cumulative)
- tier='specialized' → load core + extended + specialized (cumulative = all)
- tier='all'         → load all fragments (same as specialized)

Rationale: an agent running an extended pass needs core context too. Loading 'extended'
without 'core' would produce incomplete agent context.

<!-- MET-ERG-06 token budget (from ROADMAP.md Operator-Cost Metrics). -->

Per-step context budget: < 15 000 tokens when core tier only is loaded.
Token approximation: Math.ceil(totalCharCount / 4).

<!-- MET-ERG-07 reduction target (FRAG-04). -->

core-only tokenCount / all-tier tokenCount < 0.60
(i.e., core-only is at least 40% smaller than loading all tiers)

This must hold for each of the three governance agents independently when measured
against their actual fragment files as written by Plans 02-03/04/05.

describe('cumulative tier semantics (FRAG-02)', () => {
  // Uses real agent dirs — skips if agents not yet built
  const interrogatorDir = path.resolve(process.cwd(), '.agents/skills/terrace-spec-interrogator');

  it('extended tier includes core fragments (FRAG-02)', () => {
    if (!fs.existsSync(path.join(interrogatorDir, 'fragments', 'fragment-index.json'))) {
      return; // agent not built yet
    }
    const result = loadFragments(interrogatorDir, { tier: 'extended' });
    const tiers = result.fragments.map(f => f.tier);
    expect(tiers).toContain('core');
    expect(tiers).toContain('extended');
  });

  it('core tier excludes extended fragments (FRAG-02)', () => {
    if (!fs.existsSync(path.join(interrogatorDir, 'fragments', 'fragment-index.json'))) return;
    const result = loadFragments(interrogatorDir, { tier: 'core' });
    expect(result.fragments.every(f => f.tier === 'core')).toBe(true);
  });
});

describe('MET-ERG-07: ≥40% context reduction from core-only loading (FRAG-04)', () => {
  const agents = [
    '.agents/skills/terrace-spec-interrogator',
    '.agents/skills/terrace-spec-compiler',
    '.agents/skills/terrace-test-architect',
  ];

  for (const agentRelPath of agents) {
    it(`core-only load is ≥40% smaller than all-tier for ${agentRelPath} (FRAG-04, MET-ERG-07)`, () => {
      const agentDir = path.resolve(process.cwd(), agentRelPath);
      if (!fs.existsSync(path.join(agentDir, 'fragments', 'fragment-index.json'))) return;
      const coreResult = loadFragments(agentDir, { tier: 'core' });
      const allResult  = loadFragments(agentDir, { tier: 'all' });
      if (allResult.tokenCount === 0) return; // no fragments yet
      const ratio = coreResult.tokenCount / allResult.tokenCount;
      expect(ratio).toBeLessThan(0.60); // core is ≥40% smaller
    });
  }
});

describe('MET-ERG-06: per-step core context < 15000 tokens', () => {
