}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI → target repo filesystem | terrace init writes files to process.cwd(); path must not escape cwd |
| template directory → CLI | Templates read from __dirname/templates/ — read-only, no user input involved |
| init output paths | All paths are hardcoded strings joined with path.join(process.cwd(), ...) — no user-controlled path segments |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-05 | Tampering | terrace-tools.cjs handleInit | mitigate | All output paths are hardcoded `path.join(process.cwd(), staticSegment)` — no user input is used to construct output paths in init; path traversal via init args is not possible because init takes no file path args |
| T-00-06 | Denial of Service | writeFile creating deep dirs | accept | `fs.mkdirSync(... { recursive: true })` only creates dirs under process.cwd(); limited blast radius; no user-controlled depth |
| T-00-07 | Tampering | JSON write to project-state.json | mitigate | Use `JSON.stringify(data, null, 2)` with a validated object literal — not user input — before write; no parse step that could corrupt on malformed input |
| T-00-08 | Information Disclosure | template files read from __dirname | accept | Templates are static committed files; no sensitive data; read-only operation |
</threat_model>
